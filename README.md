# Taxi Curuçá — Administração

Central administrativa do Taxi Curuçá, com acesso restrito a administradores autorizados.

- Acompanhamento de viagens, motoristas e passageiros em tempo real.
- Análise de solicitações de cadastro de motoristas.
- Gestão de trajetos, tarifas, vagas e disponibilidade.
- Consulta de conversas e histórico de ações administrativas.
- Busca, filtros e exportação de relatórios CSV.

Desenvolvido em HTML, CSS e JavaScript, com Firebase Authentication e Cloud Firestore.
